Data & method

Description-only prompts are paired with named-entity calibrations. Their wording also differs, so this comparison does not isolate the effect of naming alone.


Controls
    

  • No-op: the same forward hook returns its input unchanged. Its logits must match the clean run.
    • 

  • Unrelated swap: exchanges the fixed “table” / “music” pair. It is a semantic negative control, not a norm-matched edit.
    • 

  • Direct-answer swap: exchanges original / alternative answer-token coordinates. It tests how easily the output can be pushed directly; it is not an intermediate-concept test.
    • 

  • Random, norm-matched: a seeded random direction with each token's pre-rounding edit norm matched to the concept swap. One seed per case/layer is a pilot control, not a significance estimate.
    • 

The effect plot defaults to the concept edit and negative controls. The optional direct-answer edit is always present in the exported comparison. All conditions use the same unedited text. A positive margin change can reflect suppression of the original answer, not increased alternative support.


Tokens & diagnostics
Readout ranks use the strongest declared surface. Edits use the first available surface in the frozen order: leading-space original spelling, plain spelling, leading-space title case, plain title case. The edited token is not selected using its measured rank. No single-token surface means unavailable; it does not mean the concept is absent from Qwen.


Source & limits
The published n=1,000 Qwen lens is reused. There is no Qwen fine-tuning and no new lens training. The intervention uses v = U[token] @ J[layer], projects onto the two-vector span with a pseudoinverse, exchanges those coefficients, and keeps the orthogonal complement. It omits the paper's clamping / range calibration and normalization-factor treatment. This is a paper-inspired Qwen pilot, not a reproduction of the paper's Claude result.
Even a successful concept swap establishes only a local effect under this protocol. Raw token-vector edits can be large or off-distribution; diagnostics and negative controls do not eliminate that risk.
Probability experiments edit a single forward over the prefix; edited greedy text instead uses a sustained layer-24 hook. Neither readout position nor the generation layer was selected after seeing the answer.
Designed prompts and paraphrases form a small exploratory suite, not a random benchmark. Alias masses are not factual accuracy scores. Numeric signs are retained without statistical significance claims. Offline viewer; Iteration 1 measurements are unchanged. Browser-rendered and accessibility QA are pending.
